# 山河诗卷 · 三维水墨诗词地图

由 `poemMap`（Leaflet 二维诗词地图）重新开发而来：先秦至宋 325 首诗词、155 处地标，落在一片程序生成的体素山河上。

## 运行

- **发行版**：双击 `dist/index.html`，完全离线。首屏只加载页面、`js/core.js`（诗题诗句与地点）和 `js/three.js`，gzip 后合计约 275 KB。译文注释（`js/detail.js`）、标题与巡游用毛笔字（`fonts/brush-tour.js`）、诗卷毛笔字（`fonts/brush-poems.js`）都在空闲时或第一次用到时再加载；缺了这些文件页面照常运行，只是相应内容暂缺或改用楷体。
- **源码版**：双击根目录 `index.html`（引用 `vendor/`、`data/`、`fonts/`），同样离线，适合修改调试。
- 需要支持 WebGL 2 和 `DecompressionStream` 的浏览器（Chrome/Edge 80+、Safari 16.4+、Firefox 113+）。

## 构建

```bash
npm install          # 仅构建用：three@0.160.0、esbuild、subset-font（都不进入成品）
npm run data         # 从旧项目导出 data/poems.js、data/landmask.js
npm run build        # 巡游路线 → 书法字体子集 → 按需打包 three → 单文件 dist/index.html
```

`npm run build` 依次执行：

- `tools/build-tour.mjs`：生成 `data/tour.js`（巡游路线与选诗）。
- `tools/build-font.mjs`：把马善政毛笔楷书裁成只含巡游题诗用字的子集，生成 `fonts/brush.css`（内嵌 data URI）。
- `tools/build.mjs`：按需打包 three，并生成单文件发行版。

## 地图与渲染

- **方块造型**：全国用较粗的体素网格（高 0.95 / 衡 1.1 / 轻 1.3），每个方块顶沿一圈草皮、其下土层或岩层，像 Minecraft 那样干净利落。
- **十处名胜微缩景**：长安、洛阳、杭州、金陵、黄鹤楼、庐山、岳阳楼、苏州、成都、扬州，各用 6 倍细的局部体素地形，按历史意象营造。
  - 城池：长安有城墙、大殿和大雁塔，洛阳有宫阙和双阙，金陵有城墙和钟山。
  - 水乡：杭州有西湖、苏堤白堤、雷峰保俶二塔和钱塘江，苏州有园林、太湖石和小桥流水，扬州有瘦西湖、五亭桥和白塔。
  - 名楼与山水：黄鹤楼、岳阳楼临江湖，庐山有群峰和瀑布，成都有古城、草堂和竹林。
  - 天然河道穿过被城池挡住的景区时，会沿外圈自动改道；景区与四周地形平缓相接。落在景区里的其他地点（如渭城、华清宫）会挪到景外。
- **河岸与水色**：河宽随低频噪声伸缩，岸线仍是方块却自然弯曲；地名附近的岸线保持原样，地名不会被挪动。
  - 挨着陆地的水格抬成浅滩，河心较深。
  - 水色按深度三段过渡：浅处石绿，中段石青，深处黛青。
  - 倒影收敛，远处淡成天色；水面是按小方块起伏的像素水纹。
  - 近岸点缀卵石与芦苇，树木不会落进水里。
- **建筑远近**：镜头拉到全国尺度时，楼阁民居换成「墙身 + 屋顶」的简化块，三角面减少约两成；推近后恢复原模型。
- **建筑辨识**：岳阳楼是三层盔顶，与黄鹤楼的五重檐区分开；只有一两首诗的地点按序号轮换茅舍、亭子、民居或小殿，不再千篇一律。
- **江河标记**：长江（石青）、黄河（赭黄）与长城一样，镜头拉远时显出墨线，并有名签。
- **聚焦投影**：诗词集中的东部腹地放大刻画，西部、北部与南海压缩作背景。远处地形 2×2 合并，草木分块剔除，阴影按需重绘。
- **默认视角**：自东南海上低空远眺，从南岭、江南一直望到秦岭和青藏高原。
- **意境**：「春 · 昼 · 晴」按钮展开折叠面板，里面三组：
  - **时辰**：晨 · 昼 · 暮 · 夜。
  - **四季**：春 · 夏 · 秋 · 冬。
  - **天气**：晴 · 雨；冬季的「雨」即下雪。
  - 三者可以任意叠加，选择会被记住。
- **飘落**：春天飘樱瓣，夏天飘竹叶，秋天飘枫叶，数量克制；下雨下雪时飘叶减弱。
- **草木随远近增减**：远处按分块显示全局草木。镜头推近（40 单位内）时，在视点周围按同一规则补种一层近景林团，越近越密，平原上也有成片的村树竹丛，其间留出空地。上限随画质：高 9000、衡 6000、轻 2500 株。
- **树种与季节**：松、竹常绿，秋冬不变黄；柳与枫随季变色；只有阔叶花树在春天开花。
- **光影**：昼间太阳高约 54°，晨暮约 22°，影子短而贴身，不会从台阶上「飘」到下一级。
- **近景细节**：点开某处（或巡游停在某处）时，周围添上行人往来、灯笼、盘旋的飞鸟、炊烟和花草。
- **长城**：沿明长城走向随山脊蜿蜒，有敌楼和三座关城。拉远时显出一道赭红墨线，并有名签。
- **庐山瀑布**：主峰侧开出一面崖壁，飞瀑顺崖而下，水帘流动、潭口起水雾。
- **夜景近看**：夜里镜头推近时，孔明灯从地面缓缓升空，水面漂着莲花河灯。
- **名胜**：城池（长安、洛阳、汴京、金陵、彭城）、水乡（杭州、苏州、扬州、山阴、成都）和名楼单独营造。水乡的石拱桥只架在河窄处，两端落在岸上。

## 巡游

- **路线**：江南 → 洛阳 → 长安 → 三峡 → 川蜀 → 边塞。
  - 每个片区按唐宋八大家的诗作数、唐诗数、诗作总数挑选两三处，片区内的顺序按最短路径排，镜头不折返。
  - 每站配一首唐诗、一首宋诗词，各自优先选八大家。全程唐诗 17 首、宋词 9 首；首轮先展示唐诗为主（10:3），第二轮换另一首。
- **四季与时辰、天气**：
  - **季节**：路线分四段（江南 · 中原 · 巴蜀 · 边塞）各占一季，每巡一轮顺移一季，每个地方都会轮到四季。
  - **时辰**：段内各站错开晨、昼、暮、夜。夜只落在繁华处（城池、水乡、名楼或诗多之地），先暮后夜，华灯初上。
  - **诗意优先**：诗里有「夜 / 月」就安排夜，「朝 / 晓」就安排晨，「暮 / 夕」就安排暮，有「雨 / 雪」就下雨下雪。
  - **天气**：其余按季节概率取固定种子的伪随机，每段至少一晴一雨、雨雪不超过一半。每次巡游的安排都一样，但每一轮不同。
- **避山**：飞行前沿途量出地形净空，镜头会在山前提前平滑爬升；落定后环绕时，如果下一步会贴山或被山挡住视线，就反向环绕。
- **运镜**：片区之间先升高、远渡、再推近；片区内短距滑移；落定后缓慢环绕并微微推近，起止都有缓冲。
- **诗卷字体**：手卷里的诗题、诗句、地名与印章也用毛笔楷书（开页三秒后在后台加载，或首次展卷时加载）。译文、注释仍用楷体。
- **题诗**：右侧展开一幅小立轴，写诗题、朝代作者、末两句（多为点题）和作者印，用毛笔楷书，自上而下展开。由「巡游题诗」按钮控制开关。
- **巡游设置**（右下调节按钮，或巡游中小条上的「设置」）：
  - **速度**：普通 / 快 / 特快，即 1× / 1.5× / 2×。
  - **数量**：普通（每片区 2–3 处）/ 多（每片区再加 2 处）/ 无尽（循环不止，每轮换季换诗）。
  - **停留**：短 / 中 / 长。**镜头**：近景 / 中景 / 远景。
  - **雨雪**：少（默认，每段至多一站）/ 常 / 无。**意境**：随站变化 / 保持当前。
  - 设置会被记住；「普通」「多」巡游一周后回到全景。
- **控件**：巡游时底部控件自动收起，只留「巡游中 · 控件 · 停止」小条。拖动或点击画面即可接管镜头，巡游随之停止。

## 诗人足迹

- 入口有两个：右上搜索框旁的足迹图标（列出全部诗人，点一下就开始），或诗卷底栏的「某某足迹」。
- 播放时镜头由系统运镜，暂不响应拖动；走完、或在年谱里点某站之后，镜头交还给你。
- 一生分作春夏秋冬依次变换，天气以晴为主（偶有雨雪，固定种子）；退出后还原你原来的意境设置。
- 同一地点去过多次时，每次显示不同的代表作。镜头在每站会自动绕开挡住视线的山体。
- 在李白、杜甫、王维、白居易、苏轼的诗卷底栏点「某某足迹」（李白 19 站、杜甫 15 站、王维 11 站、白居易 12 站、苏轼 17 站，各有一色）。
- **跟随运镜**：镜头先飞到第一站的中景，随后跟着笔头从一站行到下一站；远途时镜头稍稍拉高，到站再推近。每到一站停留片刻，右侧展开小立轴，题写此人在当地的代表作末两句。
- **地图上的站点卡**：到站时，年份、地名和一句事略浮现在地点旁，启程时淡去；年谱在播放时收成一行进度，走完或暂停后再展开。
- **光带**：足迹是一条朱红、半透明、带金色流光的光带，内芯实、外晕柔，沿线有流光。年岁越后，弧线越高、颜色越深，重叠的行程能分出上下先后。远看时光带仍保持一定宽度。
- **收束**：走完全程后，镜头拉远成斜俯视，把全部行迹装进年谱右侧的空白处。
- **年谱**：左侧年谱逐站写明年份、地点和事略，当前一站高亮。点任一站，镜头飞到那里。
- **按钮**：「全程」直接看整体，「重播」从头再走一遍；拖动镜头即改由你自己控制，按 Esc 或 × 退出。

## 操作

- 左键旋转，右键平移，滚轮 / 双指缩放，`WASD` 漫游。
- `1`–`6`：全国 · 江南 · 三峡 · 长安 · 长城 · 边塞。`R` 回到默认视角，`T` 巡游，`H` 隐藏界面，`P` 保存画面。
- 右下按钮依次是：重置、巡游、巡游题诗、自动推镜、环境音、保存画面、画质、隐藏界面。
  - **自动推镜**：点地名时镜头自动推近；关掉后镜头不动，由你自己调整。搜索和诗词链接仍会带你过去。
- **点地名**：一首直接展开手卷；多首先在地点旁弹出「诗目」竖向列表。手卷里 `←` `→` 换首，`Esc` 先回诗目再关闭。
- 每首诗有自己的链接 `index.html#/p/<诗的 id>`。
