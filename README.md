# 山河诗卷 · 三维水墨诗词地图

由 `poemMap`（Leaflet 二维诗词地图）重新开发而来：先秦至宋 325 首诗词、155 处地标，
落在一片程序生成的体素山河上。点地名读诗：一处一首直接展卷，一处多首先出「诗目」，择一首再展开立轴。

## 运行

**直接双击 `index.html` 即可**，完全离线：不联网、不加载网络字体，也不需要本地服务。
需要支持 WebGL 2 的浏览器（新版 Chrome / Edge 已实测；Firefox / Safari 未测）。

也可以起一个本地服务：`node tools/serve.mjs 5188`，然后打开 http://127.0.0.1:5188/

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 全部自写的 HTML / CSS / JS（地形、体素、水面、建筑、诗目与诗卷、音频） |
| `vendor/three-bundle.js` | three.js r160 及所用扩展的本地打包（MIT，见 `three-LICENSE.txt`） |
| `data/poems.js` · `data/land.js` | 诗词作者数据、中国陆地轮廓（由旧项目导出） |
| `tools/build-data.mjs` | 从旧项目 `src/data` 重新导出数据 |
| `tools/three-entry.js` | 重新打包 vendor 的入口（用 esbuild 打成 iife） |
| `tools/serve.mjs` · `tools/shot.mjs` | 本地服务、无头截图验收（`--offline` 可断网测试） |

## 操作

- 左键拖动旋转，右键拖动平移，滚轮 / 双指缩放；`W A S D` 漫游
- 视角：`1` 全国（俯瞰全图）· `2` 江南 · `3` 三峡 · `4` 长安 · `5` 边塞；`R` 重置
- `T` 巡游 · `H` 隐藏界面 · `P` 保存画面 · `/` 搜索
- 诗卷内 `←` `→` 切换同一地点的诗，`Esc` 先回诗目再关闭
- 天色：晴 / 晨 / 暮 / 夜；环境音默认关闭，点击才播放

## 画质（右下「衡」按钮循环切换，选择会被记住）

| 档 | 默认 | 内容 |
| --- | --- | --- |
| 衡 | 桌面 | 体素 0.85、倒影隔帧更新且不画草木、2048 阴影、2×MSAA、渲染倍率 ≤1.25 |
| 高 | — | 体素 0.72、每帧全量倒影、4096 阴影、泛光、4×MSAA、渲染倍率 ≤2 |
| 轻 | 手机 | 体素 1.0、天光倒影、1024 阴影、草木 55% |

所有档位的阴影都按需重绘（只在视野移动或天色变化时更新），草木按 48 单位分块，可做视锥剔除。
开头帧率低于 26 时会自动降一档。体素精度在载入时确定，所以切换画质后要下次打开才会变。
调试用 URL 参数：`?q=high|mid|low`、`?cs=0.6`，以及 `pr` / `refl` / `msaa` / `shadow` / `flora`。

字体统一用系统楷体（Windows 楷体 / macOS 楷体-简）；没有楷体的系统会退回默认衬线字体。

## 地理说明

地形是示意性的，不是测绘数据：海岸线来自行政区划轮廓，山脉、高原、盆地、江河、湖泊是手工折线加噪声生成的，高度做了非线性夸张。
