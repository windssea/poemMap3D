# 山河诗卷 · 三维水墨诗词地图

由 `poemMap`（Leaflet 二维诗词地图）重新开发而来：先秦至宋 325 首诗词、155 处地标，落在一片程序生成的体素山河上。

## 运行

- **发行版**：双击 `dist/index.html`，单文件约 627 KB，完全离线，没有任何网络请求。
- **源码版**：双击根目录 `index.html`（引用 `vendor/`、`data/`），同样离线，适合修改调试。
- 需要支持 WebGL 2 和 `DecompressionStream` 的浏览器（Chrome/Edge 80+、Safari 16.4+、Firefox 113+）。

## 构建

```bash
npm install          # 仅构建用：three@0.160.0、esbuild（不进入成品）
npm run data         # 从旧项目导出 data/poems.js、data/landmask.js
npm run build        # 按需打包 three → vendor/，并生成单文件 dist/index.html
```

## 地图与渲染

- **聚焦投影**：诗词集中的东部腹地（约东经 103–123°、北纬 22–41°）按原比例刻画，西部高原、北方草原和南海压缩到四成作背景。
- **两级细节**：近处用整格体素，远处 2×2 合并；草木只画到一定距离内。
- **阴影按需重绘**：只在视野移动或天色、季节变化时重算。
- **四季**（春 / 夏 / 秋 / 冬）：在着色器里切换颜色，不重建模型。春有桃花嫩绿，夏是浓绿，秋为金黄丹枫，冬天北方和高处积雪、屋顶覆雪。
- **长城**：沿明长城走向平滑铺设，随山脊蜿蜒起伏，城墙有垛口、马道和砖层，每隔一段一座敌楼，夜里箭窗亮灯；山海关、居庸关、嘉峪关三座关城单独营造。镜头拉远后叠一道赭红墨线，全国视角也一眼可见；另有「万里长城」和关隘名签，点击可飞过去。
- **名胜精绘**：长安、洛阳、汴京、金陵、彭城做成有城墙、角楼、殿台和坊巷的城池；长安另有大雁塔。杭州、苏州、扬州、山阴、成都是水乡，有拱桥、塔、亭、柳和竹。黄鹤楼、多景楼是五层楼阁。黄州的赤壁江岸染成赭红。

## 操作

- 左键旋转，右键平移，滚轮 / 双指缩放，`WASD` 漫游。
- `1`–`6`：全国 · 江南 · 三峡 · 长安 · 长城 · 边塞。`R` 重置，`T` 巡游，`H` 隐藏界面，`P` 保存画面。
- 点地名：一首直接展开手卷；多首先在地点旁弹出「诗目」竖向列表（引线指向地点，超过一定高度可滚动；镜头飞行时位置不动，不会抖）。
- 手卷里滚轮或拖动横向阅读，`←` `→` 换首，`Esc` 先回诗目再关闭。
- 每首诗有自己的链接 `index.html#/p/<诗的 id>`，打开即展卷，可以分享。
- 天色、季节和画质的选择会被记住。
