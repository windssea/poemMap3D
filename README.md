# 山河诗卷 · 三维水墨诗词地图

由 `poemMap`（Leaflet 二维诗词地图）重新开发而来：先秦至宋 325 首诗词、155 处地标，落在一片程序生成的体素山河上。

## 运行

- **发行版**：双击 `dist/index.html`，完全离线。首屏只加载页面、`js/core.js`（诗题诗句与地点）和 `js/three.js`，gzip 后合计约 275 KB。译文注释（`js/detail.js`）、标题与巡游用毛笔字（`fonts/brush-tour.js`）、诗卷毛笔字（`fonts/brush-poems.js`）都在空闲时或第一次用到时再加载；缺了这些文件页面照常运行，只是相应内容暂缺或改用楷体。
- **源码版**：双击根目录 `index.html`（引用 `vendor/`、`data/`、`fonts/`），同样离线，适合修改调试。
- 需要支持 WebGL 2 和 `DecompressionStream` 的浏览器（Chrome/Edge 80+、Safari 16.4+、Firefox 113+）。

## 构建

```bash
npm install          # 仅构建用：three@0.160.0、esbuild、subset-font（都不进入成品）
npm run data         # 从旧项目导出 data/poems.js、data/landmask.js
npm run build        # 巡游路线 → 书法字体子集 → 按需打包 three → 单文件 dist/index.html
```

`npm run build` 依次执行：

- `tools/build-tour.mjs`：生成 `data/tour.js`（巡游路线与选诗）。
- `tools/build-font.mjs`：把马善政毛笔楷书裁成只含巡游题诗用字的子集，生成 `fonts/brush.css`（内嵌 data URI）。
- `tools/build.mjs`：按需打包 three，并生成单文件发行版。

## 地图与渲染

- **方块造型**：全国用较粗的体素网格（高 0.95 / 衡 1.1 / 轻 1.3），每个方块顶沿一圈草皮、其下土层或岩层，像 Minecraft 那样干净利落。
- **十处名胜微缩景**：长安、洛阳、杭州、金陵、黄鹤楼、庐山、岳阳楼、苏州、成都、扬州，各用 6 倍细的局部体素地形，按历史意象营造。
  - 城池：长安有城墙、大殿和大雁塔，洛阳有宫阙和双阙，金陵有城墙和钟山。
  - 水乡：杭州有西湖、苏堤白堤、雷峰保俶二塔和钱塘江，苏州有园林、太湖石和小桥流水，扬州有瘦西湖、五亭桥和白塔。
  - 名楼与山水：黄鹤楼、岳阳楼临江湖，庐山有群峰和瀑布，成都有古城、草堂和竹林。
  - 天然河道穿过被城池挡住的景区时，会沿外圈自动改道；景区与四周地形平缓相接。落在景区里的其他地点（如渭城、华清宫）会挪到景外。
- **河岸与水色**：河宽随低频噪声伸缩，岸线仍是方块却自然弯曲；地名附近的岸线保持原样，地名不会被挪动。
  - 挨着陆地的水格抬成浅滩，河心较深。
  - 水色按深度三段过渡：浅处石绿，中段石青，深处黛青。
  - 倒影收敛，远处淡成天色；水面是按小方块起伏的像素水纹。
  - 近岸点缀卵石与芦苇，树木不会落进水里。
- **建筑远近**：镜头拉到全国尺度时，楼阁民居换成「墙身 + 屋顶」的简化块，三角面减少约两成；推近后恢复原模型。
- **建筑辨识**：岳阳楼是三层盔顶，与黄鹤楼的五重檐区分开；只有一两首诗的地点按序号轮换茅舍、亭子、民居或小殿，不再千篇一律。
- **江河标记**：长江（石青）、黄河（赭黄）与长城一样，镜头拉远时显出墨线，并有名签。
- **聚焦投影**：诗词集中的东部腹地放大刻画，西部、北部与南海压缩作背景。远处地形 2×2 合并，草木分块剔除，阴影按需重绘。
- **默认视角**：自东南海上低空远眺，从南岭、江南一直望到秦岭和青藏高原。
- **意境**：「春 · 昼 · 晴」按钮展开折叠面板，里面三组：
  - **时辰**：晨 · 昼 · 暮 · 夜。
  - **四季**：春 · 夏 · 秋 · 冬。
  - **天气**：晴 · 雨；冬季的「雨」即下雪。
  - 三者可以任意叠加，选择会被记住。
- **飘落**：春天飘樱瓣，夏天飘竹叶，秋天飘枫叶，数量克制；下雨下雪时飘叶减弱。
- **草木随远近增减**：远处按分块显示全局草木。镜头推近（40 单位内）时，在视点周围按同一规则补种一层近景林团，越近越密，平原上也有成片的村树竹丛，其间留出空地。上限随画质：高 9000、衡 6000、轻 2500 株。
- **生态分区**：按高程、坡度、距水与地标把每格分为山地、丘陵、平原、河岸、园林、高原、陡崖。
  - 各区树种配比：山地以松为主，陡处多横枝松；丘陵松与杂木；平原只有阔叶林团与少量柳；河岸以柳为主，南方溪边有竹与桃；园林是桃、竹与庭院树；高原只有松。
  - 成片取种：同一片林子用同一优势树种（低频噪声经分位表换成均匀分布再按权重取种），约两成混入其他树种。
  - 景观空间：每格按低频噪声（分位表均匀化）归入密林、疏林或留白，各区配额——山地 45/30/25、丘陵 30/40/30、平原 12/23/65、河岸 15/55/30、园林 20/50/30、高原 5/45/50（密林/疏林/留白，%）。留白处不栽乔木、只铺地被；疏林稀疏几株；密林成片。全局草木与近景加密同一套规则。
  - 临水一侧的子格不栽树，树与水面之间留出一段岸；紧贴水的格子至少有一行岸柳。近景加密沿用同一套规则。
- **五种植物**（按 `example/` 的示例结构重写）：一律由下至上生成——根 → 主干 → 一级/二级枝 → 冠层团簇 → 叶片或花簇。枝是连续相贴的体素块（中远景一段一块「梁」），叶团是「主体 + 顶块 + 左右侧块」。
  - 柳（第二版）：粗干三段微弯，4–5 条两段主枝伸向不同方向与高度，枝端团与冠心团 5–8 团咬合；垂枝只从各枝端团下缘长出，少而粗、长短不一、逐段折线。
  - 阔叶（第二版）：饱满主冠体量 + 向不同方向与高度错位的辅助冠团 + 偏心顶冠；成熟圆冠、宽伞冠、高卵形、偏冠、庭院小树五种轮廓。
  - 松：贯穿树干，枝层由下至上收窄、各层水平错位，少量外伸横枝。直立、矮壮、疏枝三种；另有横枝景观松。
  - 桃：短主干，2–4 条两段主枝，各带一截次枝；花团围绕枝端，簇间露枝，浅粉为主、局部深粉。
  - 竹丛：3–7 根，分节竹竿 + 克制的竹节，上部左右交替的侧枝与叶簇，高度差明显。
  - 每棵树逐块记录包围盒，`VoxelTree.check(种, 变体, 细节)` 检查「不着地的连通块」，全部树种三级细节均为 0。
- **植物尺度规范**：以地图里的民居（高 0.25）为参照，每类植物一个基础高度，随机只在小范围内浮动：
  - 草簇 0.045（±15%）、灌木与芦苇 0.09–0.11（±12%）、庭院树 0.31–0.36（±10%）、成熟乔木 0.42–0.56（±8%）、景观大树 0.46–0.62（±6%）。
  - 柳：河岸柳、景观柳为成熟乔木，庭院柳为庭院树；阔叶：圆冠、宽伞、偏冠为成熟乔木，高卵形为景观大树，庭院小树为庭院树；松为成熟乔木，横枝松为景观大树；桃、竹为庭院树。
  - 摆放时按「目标高 ÷ 模型实际高」换算缩放；园林与名胜点景只用庭院小树、庭院柳，自然地带用成熟乔木。冠幅大于 0.42 的树占住相邻子格，树冠不互相穿插。
- **建筑避让与视线**：
  - 占用与缓冲：每座建筑（含城墙、敌楼、城门、桥）按实际实例取地面外轮廓，存成有向矩形分桶索引；树冠（按尺度规范的冠幅）离外轮廓至少 0.06，不伸进屋顶。岸石、芦苇、地被同样避开。
  - 入口：民居、殿、楼、亭、塔在正面留一条通道，城门两面都留，通道里不栽树。
  - 视线通道：每个诗词地点沿建筑群正面开一条扇形通道（长约 1.5 + 占地 × 2.5，封顶），通道里不栽成熟乔木与景观大树；庭院树只在后半段、且减半；地被照常。
  - 框景：地点两侧与后方一圈至少为疏林、密度加三成。
- **细节分级与实例化**：
  - 三级细节：近景（镜头周围 8 单位内）完整结构，中景减块、枝改为「梁」，远景只留体量与垂枝剪影；按树种、变体、细节共享几何，全国按 72 单位分块 InstancedMesh（实测 96、144 的大块只省少量绘制调用，却多出 0.4–0.8M 三角面）。
  - 隐藏面剔除：生成每棵树时，外侧紧贴的 9 个采样点都落在本树其他实心方块里的面直接删去（梁的近似包围盒不当遮挡体），近景阔叶 688→341、松 410→231、桃 890→576、柳 1340→1072 面，外观不变。
  - 远近切换带回差：远于 34 换远景、近于 29 才换回；镜头在交界处晃动时的切换次数 580→0。
  - 固定随机种子：树形由（树种、变体、细节）决定，位置由格坐标决定，刷新与转镜头都不变。
- **地形预览**（`terrain-preview.html` 或 `?lab=terrain&w=sanxia|lushan`，未接入全国地图）：
  - 基础高度：全国图塑形后的陆地高度（含山脉走势、名山、侵蚀）双线性插值到 5 倍细的局部网格；原有水格用四周陆地补平后重新开河。
  - 次级山脊与沟谷：扭曲后的脊状噪声 + 噪声过零处成谷，幅度与当地起伏成正比，平原不动；两遍轻度平滑去尖包；热侵蚀限制单格落差（常规 0.3–0.5，少量崖区 0.6）；统一按全国图步长 0.1 量化。
  - 河岸：真实河道中心线，到中心线距离 − 半宽（两级噪声伸缩）= 离岸距离；水位取全国图该段水位、沿流单调并平滑；河床低于水面、近岸浅；岸上 1–3.6 单位内由滩地缓升，背后有山且噪声选中的岸段为陡岩岸；湖面沿用全国图。
  - 材质分层：顶面分 水床 / 浅滩 / 湿地 / 平原 / 丘陵草地 / 山地草甸 / 裸岩 / 积雪；侧面按 草皮口 → 土层（平原 0.3、丘陵 0.18、山地 0.08）→ 岩层，水边为湿土；只在邻格更低时出侧面。水面按深度三段着色，像素化闪动，不做镜面倒影。
  - 植被（第四至六步）：只读 sample 同一套高度、坡度、分区与离岸距离。山地松为主（陡坡边缘横枝松）、丘陵松与阔叶成片、平原阔叶林团与留白、岸后 1.4 单位内缓坡柳为主并成簇；芦苇成丛落在浅水与滩边，卵石、草簇沿岸。山顶、裸岩、积雪、崖区与陡岸不栽乔木；名胜微缩景外扩两格、建筑与入口、地标视线通道禁种。按「树种:变体 × 细节级」分批 InstancedMesh，三级 LOD 按到镜头距离（6 / 16）分桶、带回差；地被远看不画。
  - 名胜微缩景（如庐山）保留自己的地形与水面；对外 `sample(x, z)` 给出 height、slope、biome、shoreDistance、water。
- **统一体素**：全国地图任何距离都是同一套方块地形（格 0.95），不再在远处换 2×2 合并的粗网格、也不在近处换细网格；远近只调整草木与建筑的细节级别，地形形状不变。地形预览（terrain-preview.html）仍是独立的试验场，不接入地图。
- **树木样板**：打开 `tree-preview.html`（或地址加 `?lab=all`）进入单树样板场景，可拖动旋转、滚轮缩放；每行依次是各变体近景，右侧为中景、远景。
- **树种与季节**：松、竹常绿，秋冬不变黄；柳与枫随季变色；只有阔叶花树在春天开花。
- **光影**：昼间太阳高约 54°，晨暮约 22°，影子短而贴身，不会从台阶上「飘」到下一级。
- **近景细节**：点开某处（或巡游停在某处）时，周围添上行人往来、灯笼、盘旋的飞鸟、炊烟和花草。
- **长城**：沿明长城走向随山脊蜿蜒，有敌楼和三座关城。拉远时显出一道赭红墨线，并有名签。
- **庐山瀑布**：主峰侧开出一面崖壁，飞瀑顺崖而下，水帘流动、潭口起水雾。
- **夜景近看**：夜里镜头推近时，孔明灯从地面缓缓升空，水面漂着莲花河灯。
- **名胜**：城池（长安、洛阳、汴京、金陵、彭城）、水乡（杭州、苏州、扬州、山阴、成都）和名楼单独营造。水乡的石拱桥只架在河窄处，两端落在岸上。

## 诗词标签

- **三级显示**（按镜头远近自动切换，带回差不闪）：
  - 全国（镜头距离 > 60）：只留十处名胜与诗最多的几处，外加万里长城、长江、黄河。地名不加悬停提示。
  - 区域（14–60）：地名全部参与排序，诗多、名篇在前。
  - 地点（< 14）：只留近处几处。点开地名即展开诗目与完整诗卷（译文、赏析、注释）。
- **避让**：地名、界面面板（工具栏、搜索、诗目、诗卷、题诗、足迹面板）之间按屏幕矩形避让；。
- **焦点**：地名旁不显示诗句预览（选中也不显示）；选中一处时它的优先级最高，周围 70px 内其他地名让开，其余地名淡到三成八，悬停时恢复。

## 巡游

- **路线**：江南 → 洛阳 → 长安 → 三峡 → 川蜀 → 边塞。
  - 每个片区按唐宋八大家的诗作数、唐诗数、诗作总数挑选两三处，片区内的顺序按最短路径排，镜头不折返。
  - 每站配一首唐诗、一首宋诗词，各自优先选八大家。全程唐诗 17 首、宋词 9 首；首轮先展示唐诗为主（10:3），第二轮换另一首。
- **四季与时辰、天气**：
  - **季节**：路线分四段（江南 · 中原 · 巴蜀 · 边塞）各占一季，每巡一轮顺移一季，每个地方都会轮到四季。
  - **时辰**：段内各站错开晨、昼、暮、夜。夜只落在繁华处（城池、水乡、名楼或诗多之地），先暮后夜，华灯初上。
  - **诗意优先**：诗里有「夜 / 月」就安排夜，「朝 / 晓」就安排晨，「暮 / 夕」就安排暮，有「雨 / 雪」就下雨下雪。
  - **天气**：其余按季节概率取固定种子的伪随机，每段至少一晴一雨、雨雪不超过一半。每次巡游的安排都一样，但每一轮不同。
- **避山**：飞行前沿途量出地形净空，镜头会在山前提前平滑爬升；落定后环绕时，如果下一步会贴山或被山挡住视线，就反向环绕。
- **运镜**：片区之间先升高、远渡、再推近；片区内短距滑移；落定后缓慢环绕并微微推近，起止都有缓冲。
- **诗卷字体**：手卷里的诗题、诗句、地名与印章也用毛笔楷书（开页三秒后在后台加载，或首次展卷时加载）。译文、注释仍用楷体。
- **题诗**：右侧展开一幅小立轴，写诗题、朝代作者、末两句（多为点题）和作者印，用毛笔楷书，自上而下展开。由「巡游题诗」按钮控制开关。
- **巡游设置**（右下调节按钮，或巡游中小条上的「设置」）：
  - **速度**：普通 / 快 / 特快，即 1× / 1.5× / 2×。
  - **数量**：普通（每片区 2–3 处）/ 多（每片区再加 2 处）/ 无尽（循环不止，每轮换季换诗）。
  - **停留**：短 / 中 / 长。**镜头**：近景 / 中景 / 远景。
  - **雨雪**：少（默认，每段至多一站）/ 常 / 无。**意境**：随站变化 / 保持当前。
  - 设置会被记住；「普通」「多」巡游一周后回到全景。
- **控件**：巡游时底部控件自动收起，只留「巡游中 · 控件 · 停止」小条。拖动或点击画面即可接管镜头，巡游随之停止。

## 诗词打标

- `data/fame.js` 为全部 325 首手工编订：每首最有名的句子（上下句，词取完整一韵）与名气 1–5，家喻户晓的顶尖名篇记 5.5；名气 ≥ 4 为「名篇」。
- 诗目里名篇带朱印，同一地点名篇在前；诗卷里名句点朱。
- 巡游每站先展示该地最有名的一首，题诗用它的名句；发行版把打标并入 `js/core.js`。

## 诗人足迹

- **节奏**：每站只显示本站的说明卡与本站的诗；启程时本站的卡随笔头飞出一小段后淡去，到下一站再换卡。到站若有诗，先停一拍再展开题诗（约 5 秒）。
- **题诗归属**：此人每首诗先归到最近的一站（地名对得上的优先），同一地点第一次到访题最有名的一首，第二次题第二有名的，该地没有诗就不题。
- **镜头**：避让山体带迟滞，不在两个角度间来回跳；镜头高度按四周地面最高处平滑抬升；播放时不再把镜头目标往脚下地面拉（庐山等台阶陡变处抖动的来源）。
- **避让**：说明卡与题诗、屏幕边缘相撞时翻到另一侧；手机上改挂到地点下方。镜头跟随时把画面重心略往左放，右侧留给题诗。
- **手机与平板**（宽 ≤ 1024 或触屏）：播放时顶部一条；结束后年谱收在底部，展开也只占三分之一屏。
- **黑屏修复**：足迹外晕着色器里 `pow` 的底数可能因浮点误差略小于 0 而得 NaN，经「高」画质的泛光多级模糊扩成大块黑屏；已钳位。
- 入口有两个：右上搜索框旁的足迹图标（列出全部诗人，点一下就开始），或诗卷底栏的「某某足迹」。
- 播放时镜头由系统运镜，暂不响应拖动；走完、或在年谱里点某站之后，镜头交还给你。
- 一生分作春夏秋冬依次变换，天气以晴为主（偶有雨雪，固定种子）；退出后还原你原来的意境设置。
- 同一地点去过多次时，每次显示不同的代表作。镜头在每站会自动绕开挡住视线的山体。
- 在李白、杜甫、王维、白居易、苏轼的诗卷底栏点「某某足迹」（李白 19 站、杜甫 15 站、王维 11 站、白居易 12 站、苏轼 17 站，各有一色）。
- **跟随运镜**：镜头先飞到第一站的中景，随后跟着笔头从一站行到下一站；远途时镜头稍稍拉高，到站再推近。每到一站停留片刻，右侧展开小立轴，题写此人在当地的代表作末两句。
- **地图上的站点卡**：到站时，年份、地名和一句事略浮现在地点旁，启程时淡去；年谱在播放时收成一行进度，走完或暂停后再展开。
- **光带**：足迹是一条朱红、半透明、带金色流光的光带，内芯实、外晕柔，沿线有流光。年岁越后，弧线越高、颜色越深，重叠的行程能分出上下先后。远看时光带仍保持一定宽度。
- **收束**：走完全程后，镜头拉远成斜俯视，把全部行迹装进年谱右侧的空白处。
- **年谱**：左侧年谱逐站写明年份、地点和事略，当前一站高亮。点任一站，镜头飞到那里。
- **按钮**：「全程」直接看整体，「重播」从头再走一遍；拖动镜头即改由你自己控制，按 Esc 或 × 退出。

## 场景主题

- 接口 `applyTheme(名)`、地址 `?theme=名`：长安夕照（暮 · 秋 · 晴，远雾 ×1.25）、江南烟雨（昼 · 春 · 雨，远雾 ×1.6、山岚 +0.12）、庐山晨雾（晨 · 夏 · 晴，山岚 +0.28）。一个主题 = 时辰 + 季节 + 天气 + 远景雾倍数 + 低处山岚 + 机位；新增只需在 THEMES 表里加一行，雾在切换时缓缓进出。

## 操作

- 工具栏最左的 ‹ 可把整排按钮收起，只留一个 ›，选择会被记住。巡游设置、意境面板再点一次按钮即收起。


- 左键旋转，右键平移，滚轮 / 双指缩放，`WASD` 漫游。
- `1`–`6`：全国 · 江南 · 三峡 · 长安 · 长城 · 边塞。`R` 回到默认视角，`T` 巡游，`H` 隐藏界面，`P` 保存画面。
- 右下按钮依次是：重置、巡游、巡游题诗、自动推镜、环境音、保存画面、画质、隐藏界面。
  - **自动推镜**：点地名时镜头自动推近；关掉后镜头不动，由你自己调整。搜索和诗词链接仍会带你过去。
- **点地名**：一首直接展开手卷；多首先在地点旁弹出「诗目」竖向列表。手卷里 `←` `→` 换首，`Esc` 先回诗目再关闭。
- 每首诗有自己的链接 `index.html#/p/<诗的 id>`。
